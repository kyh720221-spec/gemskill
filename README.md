# 제미나이 스킬 메이커 (gemskill)

Google Gemini의 **Gem(맞춤 지침, 스킬)** 을 안내형 양식으로 빠르게 만들고, 복사해서 Gemini에 붙여 넣는 모바일 우선 웹앱(PWA)입니다.

**사용하기:** https://kyh720221-spec.github.io/gemskill/

## 기능

- 프롬프트로 자동 생성: "매일 뉴스 3줄 요약해 줘"처럼 한 줄만 적으면 역할 · 목표 · 규칙 · 금지 · 출력 형식 등을 자동으로 채움 (API 키 · 네트워크 없이 기기 안에서 분석, 빈 칸만 채우기 / 모두 덮어쓰기 / 되돌리기 지원)
- 안내형 양식: 이름, 역할(페르소나), 목표, 대상 독자, 말투, 규칙, 금지 사항, 출력 형식, 예시, 참고 자료
- Google Gem 가이드(페르소나 · 할 일 · 맥락 · 형식)에 맞춘 Markdown 지침 자동 생성 + 실시간 미리보기
- 복사하기 / Gemini Gem 만들기 화면 바로 열기 / `.md` `.txt` 저장
- 시작 템플릿: 소설 문장 다듬기, 요약가, 번역가, 공부 코치, 블로그 글쓰기, 빈 양식
- 보관함(브라우저 localStorage): 저장 · 편집 · 복제 · 삭제 · 검색, JSON 전체 백업/복원
- 다듬기 프롬프트: Gemini에 붙여 넣어 지침을 더 좋게 고치는 메타 프롬프트 생성
- PWA: 홈 화면에 추가, 오프라인 작동 (API 키 · 서버 · 네트워크 호출 없음)

## 설치

- Android Chrome: 메뉴(⋮) → **홈 화면에 추가** / **앱 설치**
- Windows Chrome: 주소창 오른쪽 설치 아이콘

## 개발

빌드 도구 없이 순수 HTML / CSS / JS로 되어 있습니다. 자동 생성 로직은 `generator.js`(도메인 사전 + 한국어 요청문 → 서술문 변환 + 길이·언어·말투·독자·형식·금지 키워드 추출)에 있고, `app.js`가 양식에 연결합니다. 로컬에서 보려면 아무 정적 서버로 루트를 띄우면 됩니다.

```bash
python3 -m http.server 8080
# http://localhost:8080/
```

배포는 GitHub Pages(`main` 브랜치, 루트)를 사용합니다. 정적 자원을 바꾸면 `sw.js`의 `CACHE_VERSION`을 올려 주세요.
