      2. 
          
    2. 미리보기의 복사하기를 눌러 지침을 복사해요.
      3.

      4. 
          
    4. 더 좋은 지침을 원하면 다듬기 프롬프트를 복사해 Gemini에 보내 보세요. Gemini가 지침을 다듬어 줘요.
